# Конфигурация и безопасность

## `.env`

Файл `.env` игнорируется Git и содержит локальные настройки:

```env
VITE_OLLAMA_API=http://localhost:11434/api/generate
VITE_OLLAMA_MODEL=qwen3:1.7b
```

Шаблон без локальных секретов хранится в `.env.example`.

## Важное ограничение Vite

Любая переменная `VITE_*` доступна клиентскому JavaScript после сборки. Это не хранилище секретов. Не добавляйте туда:

- пароли;
- токены доступа;
- приватные API-ключи;
- ключи к базам данных.

Для настоящих секретов нужен серверный слой: браузер обращается к вашему backend proxy, а backend обращается к внешним сервисам с секретом в серверном окружении.

## Git

`.gitignore` исключает `node_modules`, результаты сборки, локальные `.env`, системные файлы и логи. `.env.example` разрешён для коммита.

Если секрет уже попал в Git, простого добавления в `.gitignore` недостаточно: ключ нужно отозвать, выпустить новый и удалить старое значение из истории репозитория.
