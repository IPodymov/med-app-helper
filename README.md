# МедИИ

Локальное веб-приложение на русском языке для предварительной справочной информации о симптомах. Ответы генерируются локальной моделью Ollama и не заменяют консультацию врача.

## Возможности

- стартовый экран и отдельный экран чата;
- быстрые примеры запросов о симптомах;
- потоковый вывод ответа модели;
- очистка Markdown-выделений из ответа;
- локальная Ollama в Docker без установки Ollama через Homebrew;
- адаптивная верстка для мобильных экранов.

## Требования

- macOS, Linux или Windows;
- Node.js 18+ и npm;
- Docker Desktop с Docker Compose;
- свободное место для Docker-образа и модели `qwen3:1.7b`.

## Быстрый запуск

1. Установите зависимости проекта:

   ```bash
   npm install
   ```

2. Запустите Ollama в Docker:

   ```bash
   npm run ollama:up
   ```

3. Загрузите модель в Docker volume:

   ```bash
   npm run ollama:pull
   ```

4. Запустите веб-приложение:

   ```bash
   npm run dev
   ```

Откройте адрес, который напечатает Vite, обычно `http://localhost:5173`.

## Команды

| Команда               | Назначение                      |
| --------------------- | ------------------------------- |
| `npm run dev`         | Запуск Vite в режиме разработки |
| `npm run ollama:up`   | Запуск контейнера Ollama        |
| `npm run ollama:pull` | Загрузка или обновление модели  |
| `npm run ollama:down` | Остановка контейнера            |
| `npm install`         | Установка npm-зависимостей      |

Проверить контейнер можно командой:

```bash
docker compose ps
docker compose exec ollama ollama list
```

## Переменные окружения

Локальные настройки находятся в `.env`, который не должен попадать в Git:

```env
VITE_OLLAMA_API=http://localhost:11434/api/generate
VITE_OLLAMA_MODEL=qwen3:1.7b
```

Для новых копий проекта используйте `.env.example`.

Важно: переменные с префиксом `VITE_` встраиваются в браузерный код. Не помещайте туда пароли, API-ключи и другие настоящие секреты. Если понадобится внешний закрытый API, добавьте серверный proxy и храните секреты только на сервере.

## Медицинское ограничение
